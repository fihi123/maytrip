# May Trip · 우리 가족의 후쿠오카 여행

2027년 5월 13~16일, 후쿠오카·유후인 4인 가족여행을 준비하는 페이지입니다.

- 일정: 날짜별 실제 일정 추가·수정·삭제, 장소 지도 검색, 전체 일정 인쇄
- 예약·지출: 예약 후보와 비용, 진행 상태 관리
- 준비물: 부모님 동선과 예약 준비 체크리스트
- 메모: 가족 의견 기록
- GPT 가이드: 최초 가이드의 A/B 일정과 숙소·예산 참고 자료

GPT 가이드는 예약 확정 정보가 아닙니다. 실제 일정은 빈 상태에서 시작합니다.
입력 내용은 각 브라우저에 저장하며, 준비 파일(JSON) 내려받기·불러오기로 전달할 수 있습니다.
가족 간 자동 동기화는 연결되어 있지 않습니다. 불러오기는 기존 내용을 덮어씁니다.

`index.html`을 열거나 정적 웹 서버로 제공하면 됩니다. 빌드가 필요하지 않습니다.

구성과 사용 흐름 참고: https://github.com/fihi123/trip-plan
기존 여행의 데이터나 Firebase 연결은 사용하지 않습니다.

## 예약 내역 자동 인식

일정 탭의 **예약 내역 업로드**에서 항공·숙소 PDF 또는 JPG/PNG/WEBP 이미지를 선택합니다.
PDF 텍스트를 먼저 읽으며, 스캔 PDF와 이미지는 한국어·영어 OCR로 인식합니다.
결과의 날짜·시간·장소를 수정하고 선택한 항목을 일정에 추가합니다.
숙소 체크인·체크아웃과 항공 출발·도착을 각각 일정으로 제안합니다.

- 첫 사용은 인터넷 연결이 필요합니다. PDF.js 4.10.38과 Tesseract.js 5.1.1 및 언어 데이터를 CDN에서 내려받습니다.
- 문서 원본은 브라우저에서 처리하며 서버로 전송하거나 저장하지 않습니다.
- 2027.05.13~05.16 날짜만 추가할 수 있습니다. 누락된 날짜는 직접 입력해야 합니다.
- 같은 날짜·시간·이름·장소의 일정은 중복 등록하지 않습니다.
- 파일당 15MB, 한 번에 4개, PDF당 6페이지까지 지원합니다.
- 한글·영문 예약 양식과 날짜 표기를 기반으로 한 규칙 인식입니다. 표·다단 편집·저해상도·다른 언어에서는 결과 확인과 수정이 필요합니다.
- 결제 금액은 자동 등록하지 않습니다. 인식한 예약은 검토를 위해 ‘예정’ 상태로 추가합니다.
- 파일을 읽을 수 없을 때 예약 이메일 텍스트를 직접 붙여넣어 인식할 수 있습니다.

개발 확인: `node --test tests/reservation-parser.test.cjs`
라이브러리 사용 참고: [PDF.js 예제](https://github.com/mozilla/pdf.js/blob/v4.10.38/examples/learning/helloworld.html), [Tesseract.js 설치 안내](https://github.com/naptha/tesseract.js/blob/v5.1.1/docs/local-installation.md).
