# May Trip · 우리 가족의 후쿠오카 여행

2027년 5월 13~16일, 후쿠오카·유후인 4인 가족여행을 준비하는 페이지입니다.

- 일정: 날짜별 실제 일정 추가·수정·삭제, 장소 지도 검색, 전체 일정 인쇄
- 예약·지출: 예약 후보와 비용, 진행 상태 관리
- 준비물: 부모님 동선과 예약 준비 체크리스트
- 메모: 가족 의견 기록
- GPT 가이드: 최초 가이드의 A/B 일정과 숙소·예산 참고 자료

GPT 가이드는 예약 확정 정보가 아닙니다. 실제 일정은 빈 상태에서 시작합니다.
입력 내용은 각 브라우저에 저장하며, 준비 파일(JSON) 내려받기·불러오기로 전달할 수 있습니다.
가족 간 자동 동기화는 연결되어 있지 않습니다. 불러오기는 기존 내용을 덮어씁니다.

`index.html`을 열거나 정적 웹 서버로 제공하면 됩니다. 빌드가 필요하지 않습니다.

구성과 사용 흐름 참고: https://github.com/fihi123/trip-plan
기존 여행의 데이터나 Firebase 연결은 사용하지 않습니다.
